# Trip360 website

Plain HTML, CSS and JavaScript for trip360.site. There is no build step: open
`index.html` in a browser to preview.

Rules for working here:

- Do not change `privacy.html` or `terms.html`. They are legal text, and only the
  owner changes them.
- Leave `vercel.json` and `.well-known/` as they are. They hold the hosting rules
  and the links that open the iPhone app.
- `invite.html` is opened from friend links in the app: keep its links working.
- Do not deploy, and do not connect this repo to any hosting service. The live
  site also carries parts that are not in this repo, so the owner publishes it.
- Never add keys, passwords or tokens to any file.
- Work on a branch and open a pull request for the owner to look at.
